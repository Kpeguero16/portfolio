#How I work

    
Small changes, each with proof.

    

      
01✓
Pick
Choose changes small enough to review in one sitting.

      
02✓
Reproduce
Write the check that fails on master.

      
03✓
Build
Make the change in its own worktree. Coding agents do the typing, and I read every line.

      
04✓
Prove
The same check passes on the branch, and the module's tests still pass.

      
05✓
Ship
Open a PR that states the problem, the fix and the evidence.
